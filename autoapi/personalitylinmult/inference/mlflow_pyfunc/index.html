personalitylinmult.inference.mlflow_pyfunc¶

Wrap an FI checkpoint as an MLflow pyfunc model and register it.

Training logs raw .ckpt artifacts, which mlflow models serve cannot load on their own. This module wraps a checkpoint in the standard pyfunc flavour — a self-contained model MLflow can serve as a REST endpoint or bake into a Docker image — and registers it in the Model Registry so it carries a version.

Promotion uses aliases (set_champion()), not the deprecated Staging / Production stage mechanism: an alias is scoped to one registered-model name, so each model family (e.g. the AVT fusion model and the audio-only model) keeps its own independent @champion without any conflict, and moving the alias to a new version is a single, deliberate call – never automatic on registration.

The wrapped model consumes the same per-modality features as FiPredictor: at serving time the JSON payload is {"inputs": {"wavlm": [[...]], "emotion2vec": [[...]]}} — one (T, F) array per feature the model expects.

personalitylinmult.inference.mlflow_pyfunc.set_champion(registered_model_name: str, version: str, alias: str = 'champion') → None[source]¶

Promote a registered version to an alias.

A deliberate, separate step from registration: a new version is never auto-promoted, so a run finishing (or even being registered) never silently changes what a deployment currently serves. Aliases are per registered-model name, so multiple model families (AVT, audio-only, …) each carry their own independent @champion with no conflict.

Parameters:

  • registered_model_name (str) – The registered model name.

  • version (str) – The version to promote.

  • alias (str) – Alias to set. Defaults to "champion"; a second alias (e.g. "candidate") can stage a version before promoting it.
