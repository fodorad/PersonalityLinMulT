personalitylinmult.inference.audio_features_onnx¶

Extract WavLM features via ONNX Runtime – no torch/transformers.

The ONNX Runtime-backed counterpart to extract_wavlm(). Decoding still shells out to ffmpeg (a subprocess, not a Python dependency) to produce mono 16 kHz PCM WAV directly – WavLM’s own required sample rate – avoiding torchaudio, which would otherwise pull torch back in just for resampling. Reading the WAV uses only the standard library’s wave module plus numpy, both already required.

Known limitation: ffmpeg’s resampler and torchaudio’s Resample transform (used by the PyTorch path, via exordium.audio.wavlm.WavlmWrapper) use different filter implementations, so they do not produce bit-identical 16 kHz waveforms from the same source file (~3e-4 mean, ~2.5e-2 max absolute sample difference, measured on a real clip). WavLM’s transformer layers can amplify this at a handful of frames, but the final Big Five predictions shift only ~0.001-0.004 per trait end to end – small and bounded, not exact. Accepted deliberately to keep this module genuinely torch-free.
