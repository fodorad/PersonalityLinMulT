personalitylinmult.inference.predictor¶

Load a trained FI checkpoint and predict Big Five scores from features.

A checkpoint is self-describing: FiLightningModule.load_from_checkpoint() rebuilds the exact model from the feature_names / input_feature_dim / configs stored in its hyperparameters, so FiPredictor needs no external metadata — the path alone is enough.

The predictor is deliberately model-agnostic (the checkpoint decides which features it consumes and which traits it emits), so the same class serves the audio-only (A) and full multimodal (AVT) models without a code change.
