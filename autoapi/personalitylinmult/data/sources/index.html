personalitylinmult.data.sources¶

Readers for each on-disk feature format produced by preprocess/fi.

Every reader returns the same thing — a FeatureSample of features plus a mask — so the builder can treat WavLM pickles, DINOv2 safetensors and RoBERTa HDF5 datasets identically.

Masks. Only the track-based extractors (EmotiEffNet, FaRL, MARLIN) record a real mask, because the protagonist is not detected on every frame. The other formats are dense by construction and get an all-True mask synthesised here. Producing a mask unconditionally is what lets the rest of the pipeline hold a single contract: every sequence feature has a mask, True = valid.

AppleDouble files. This repository lives on a non-native filesystem where macOS writes ._{name} resource-fork sidecars next to real files. A naive glob("*.st") returns twice as many paths as there are clips, and reading one raises SafetensorError: header too large. iter_feature_files() filters them; use it rather than globbing directly.

personalitylinmult.data.sources.read_pickle_layers(path: pathlib.Path, layers: tuple[int, Ellipsis]) → FeatureSample¶

Read selected transformer layers from a pickled list of per-layer arrays.

Used for WavLM. layers always names model layers (9 means WavLM’s layer 9), never positions in the file, so the same config reads both supported on-disk formats:

  • {"layers": [...], "features": [...]} — what personalitylinmult.preprocess.fi.acoustic_wavlm writes now: only the extracted layers, each tagged with its model layer id.

  • a bare list of every layer — the older, fatter format, where position happens to equal the layer id.

The distinction matters because the current extractor stores one layer per clip: in a bare list that array would sit at index 0 and be indistinguishable from layer 0. Carrying the ids makes the file self-describing instead.

The pickles are produced locally by personalitylinmult.preprocess.fi from the operator’s own audio, so they are trusted input.

Parameters:

  • path (Path) – Path to the .pkl file.

  • layers (tuple[int, ...]) – Model layer ids to keep, in order.

Returns:

(T, D) when one layer is selected, (L, T, D) when several. The mask is dense.

Return type:

FeatureSample

Raises:

SourceError – If the file is unreadable or a requested layer is absent.

class personalitylinmult.data.sources.FeatureReader(spec: personalitylinmult.data.schema.FeatureSpec, root: pathlib.Path)¶

Reads one feature for arbitrary clips, holding open handles as needed.

hdf5_per_id features live in a single file keyed by video_id, so the handle is opened once and reused; the per-clip formats are opened on demand. Use as a context manager so the handle is always released.
