Baselines, eGeMAPS and a WavLM probe¶

Small experiments around the wavlm_best-ccc champion. All Big Five, seed 42, one run per row, test split. Every trained row uses the champion recipe (AdamW 5e-3, weight decay 0.05, cosine schedule with 15% warmup, gradient clip 1.0, early stopping on valid/mean_ccc, batch 256 effective). Only the loss or the input differs, as stated per row.

The eGeMAPS features and the experiment HDF5 are local, temporary artifacts: they are not published and not part of the reproducible pipeline.

  • Train-mean. The constant prediction has zero variance, so Pearson r is 0/0 (undefined) and CCC is exactly 0. Its 1-MAE of 0.8814 is the number any model has to beat, and it is why 1-MAE alone is a weak metric here.

  • Random input. With an input unrelated to the target the network converges to the mean: 1-MAE 0.8810, CCC about 0, predictions with 6.6% of the target spread.

  • eGeMAPS, loss comparison. The same input and model, trained with l1 or ccc, lands in different places: l1 gives the best 1-MAE (0.8973, above WavLM) but under-spread predictions (std_ratio 0.64), while ccc gives higher correlation (0.4908) but over-spread predictions (std_ratio 1.15, negative R2). The loss decides which part of the target distribution the model reproduces.

  • eGeMAPS vs WavLM. Low-level prosodic and spectral descriptors carry signal (CCC 0.49) but clearly less than WavLM (0.56).

  • Fusion. Adding eGeMAPS to WavLM (LinMulT, two streams) does not help: CCC 0.5543 vs 0.5604 for WavLM alone, and 1-MAE 0.8856 vs 0.8918. With one seed per row the small drop is within run-to-run noise, so the safe reading is “no gain”. Together with the probe below, this says the eGeMAPS information is largely contained in WavLM rather than complementary to it.

Linear probe: can WavLM reconstruct eGeMAPS?¶

Ridge regression (closed form, penalty chosen on validation) from the 768-d WavLM layer-9 frame to the 25 z-scored eGeMAPS LLDs. eGeMAPS (100 Hz) is average-pooled 2:1 to WavLM’s 50 Hz; padding is masked, unvoiced frames are kept. Test split.

  • WavLM linearly recovers a substantial part of eGeMAPS (R2 0.38), and the 1000-clip subset gives the same number as the full train set.

  • An untrained, randomly initialised WavLM already reaches 0.28, so the trained model’s own contribution is the gap above that (about +0.10).

  • The reverse direction is weak (R2 0.04): 25 hand-designed descriptors explain almost none of WavLM’s 768 dimensions. WavLM contains much of eGeMAPS and a lot more.
