personalitylinmult.inference.cli
================================

.. py:module:: personalitylinmult.inference.cli

.. autoapi-nested-parse::

   Command-line inference: features in, Big Five scores out.

   .. rubric:: Example

   Predict with the audio-only model from an ``.npz`` of features::

       uv run python -m personalitylinmult.inference             --checkpoint results/FI/bigfive/checkpoints/best.ckpt             --features clip_features.npz

   The ``.npz`` holds one ``(T, F)`` array per feature the model expects, keyed by
   feature name (``wavlm``, ``emotion2vec``, ...).
