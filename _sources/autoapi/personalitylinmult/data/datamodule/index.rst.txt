.. py:function:: seed_worker(worker_id: int) -> None

   Seed a dataloader worker's RNGs from torch's per-worker seed.

   Without this, every worker inherits the parent's numpy seed and augmentation
   draws repeat across workers.

   :param worker_id: Worker index, unused but required by the hook.
   :type worker_id: int

   .. attribute:: prepare_data_per_node

      If True, each LOCAL_RANK=0 will call prepare data.
      Otherwise only NODE_RANK=0, LOCAL_RANK=0 will prepare data.

   .. attribute:: allow_zero_length_dataloader_with_multiple_devices
